# Futurist Lantern

A 3D energy core you charge in the browser: a lantern of cyan light under a wireframe shell, with a ring that orbits on the floor below. Drag the ring or tap the centre and the core powers up while a voice reads the Futurist Oath, line by line.

**Try it live:** https://augmaimaginarium.com/lantern/
Part of **Augma Repo**, the free shelf of tools and studies from Augma Imaginarium: https://repo.augmaimaginarium.com

## Run it locally

It's a static web page. Serve this folder with any static server and open it in a browser:

```
npx serve .
```
